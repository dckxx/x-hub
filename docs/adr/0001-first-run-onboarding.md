# 0001-首次使用引导（快速设置弹窗 + 帮助视图）

> **状态：已决策，未实施**（截至 v0.3.0，代码中无对应实现；相关术语已预登记于 `CONTEXT.md`「引导」节，排期登记见 `AGENTS.md`「待实现」）。

首次启动引导采用「轻量快速设置弹窗（三步，<60s，可跳过）」+「侧栏常驻帮助视图」的组合形态，而非全屏欢迎向导（太重）或 spotlight 高亮引导（在 Tauri WebView 实现成本高、布局变动即失准）。

「首次运行」判定为：配置缺 `onboarding_done` 标记 **且** 数据库核心表（resources/notes/todos/countdowns）全空。只靠配置字段默认值会把老用户升级误判为新用户；该判定在 Rust 侧 `get_initial_data` 计算，前端零逻辑。

引导仅首次自动弹出，之后靠帮助视图底部「重新查看首次引导」手动重开，避免打扰老用户。快速设置不含 AI 配置（进阶项，拖长引导）。
