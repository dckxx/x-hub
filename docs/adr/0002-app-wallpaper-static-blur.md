# 0002-应用壁纸的毛玻璃用「整屏静态模糊层」，不用 backdrop-filter

> **状态：已决策，随应用壁纸功能实施。**

应用壁纸 + 卡片玻璃透明度（见 `CONTEXT.md`「主题与外观」）需要半透明卡片透出背景图。经典做法是给卡片加 `backdrop-filter: blur()` 做局部取景毛玻璃，但 v0.1.13 的 GPU 性能约束明确禁止常驻表面使用 `backdrop-filter`（逐帧重采样开销）。因此改为：**壁纸本身渲染在一个固定定位的静态层上，模糊直接作用于该层**（CSS `filter: blur`，静态内容一次合成、仅窗口 resize/换图时重绘），卡片只用半透明表面盖在上面，视觉上等效毛玻璃且不触碰红线。

**代价（接受）**：模糊是整屏的——卡片之间空隙透出的壁纸同样被柔化，无法做到「卡片后面糊、空隙清晰」的分区效果；那是 backdrop-filter 独有的能力，若未来要分区效果，必须先推翻 v0.1.13 约束，属于独立决策。

**落点**：模糊开关只作用于壁纸层（无壁纸时无此层，设置项随之隐藏），渐变预设背景不模糊。
