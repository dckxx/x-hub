# 0003-沉浸模式：卡片 backdrop-filter 的受控例外

> **状态：已决策，随应用壁纸功能实施。**

v0.1.13 的 GPU 性能约束禁止常驻表面使用 `backdrop-filter`（见 ADR 0002 的背景）。应用壁纸出现后，「壁纸完整展示 + 卡片透底仍可读」的诉求只有**局部取景模糊**能满足：壁纸在卡片间隙保持清晰，仅卡片背后那块被模糊提亮，文字自动获得稳定底色——整屏静态模糊（ADR 0002）做不到这一点（它把间隙也糊掉）。因此新增 **opt-in「沉浸模式」**（`wallpaper_immersive`，默认关）作为红线的受控例外：

- 仅对**静态** `.card` 表面启用 `backdrop-filter: blur(16px) saturate(160%)`；卡片基底 alpha 大幅下调（亮 0.18/0.12、暗 0.10/0.06，仍乘 `--glass-dim`）。
- 铬件（侧栏/标题栏）在**任何壁纸形态下都保持全透明**，与背景（渐变/壁纸）构成同一个连续平面，表面只属于卡片——曾试过给铬件垫玻璃材质/浅蒙纱，与中间背景观感割裂，明确弃用；铬件文字对比度由壁纸蒙版负责。
- 开启时整屏静态模糊自动让位（间隙必须清晰），蒙版与玻璃透明度继续生效。
- 默认形态不变（烘焙渐变伪毛玻璃，零 blur），性能红线对默认体验依然成立。

**代价（接受）**：低端核显在滚动密集列表时可能掉帧，由用户 opt-in 自担。红线本身仍然生效——动画/周期更新表面（水波、进度条、tooltip）任何模式下不得使用 backdrop-filter；若未来想把沉浸模式改为默认，需重新评估 v0.1.13 约束。
