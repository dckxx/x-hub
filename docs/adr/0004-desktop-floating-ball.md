# 0004-桌面悬浮球（环形快捷菜单导航枢纽）

> **状态：已实施**（v0.5.0：Rust 侧 `floating_ball.rs` + 前端 `FloatingBallWindow.vue`；术语见 `CONTEXT.md`「桌面悬浮球」节）。

桌面悬浮球采用「**导航枢纽 + 环形快捷菜单**」形态，而非面板式快捷启动器（macOS Dock 式）或纯状态球：单击球体在周围展开一圈圆形按钮（大圆径向排布，非六边形/九宫格），直达现有功能；球体本身保持简洁（产品 icon 的 3D 玻璃质感球）。

## 关键决策

- **常驻方式**：仅主窗口隐藏时显示（主窗口打开即收起），与托盘 + `Ctrl+Shift+Space` 心智衔接；**常驻独立透明无边框置顶窗口**（复用 countdown_window.rs 的窗口模式），非惰性创建，避免每次唤出 0.5s+ 延迟。
- **平台范围**：Windows-only，`#[cfg(target_os = "windows")]` 隔离，macOS 留待后续。
- **交互模型**：拖拽移动并记忆位置（可停在任意位置）/ **靠近屏幕边缘时才自动吸附**（不隐藏，不收起只留边）/ 单击展开环形菜单 / 双击显示主窗口 / 右键弹出与托盘一致的菜单 / 悬停球体 3D 光泽旋转（无 tooltip 提示）。
- **空间自适应**：环形菜单展开时若靠边导致按钮显示不全，悬浮球自动向左/右临时挪位保证大圆完整显示，收起后回到吸附位置。
- **按钮语义**：混合型——按钮可配置为「切换现有视图」或「快捷动作（唤起全局搜索/剪贴板/AI 面板/新建速记等）」，默认 6 个，在设置中可增删调整。
- **设置入口**：设置页「常规」分区（启用开关 + 环形按钮配置 + 吸附开关），默认开启。
- **视觉**：产品 icon 置于 **3D 玻璃质感球体**上（多向径向渐变营造球面高光/暗边 + 内圈光晕），悬停时球面光泽扫光旋转 + 光晕呼吸，与现有 Bento 玻璃风格统一。球体不设状态点、不做提示。
- **关闭方式**：点击环形外空白 / 再点球体 / Esc / 窗口失焦，四种均可收起。
- **与托盘分工**：共存——托盘管退出 + 窗口显隐，悬浮球管桌面可视化入口；右键菜单复用托盘菜单定义，改一处两处生效。

## 放弃的备选

- 纯快捷启动器面板（Q1-A）：一键直达价值大但与本项目「全局快捷键 + 托盘」现有入口重复，且面板形态无径向菜单的科技感。
- 状态球（Q1-B）：状态类能力二期再补，避免一版贪多。
- 惰性创建窗口（Q7-B）：每次唤出有窗口创建延迟，与「桌面常驻入口」定位矛盾。

## 实施修订（v0.5.0）

- **开关不再销毁窗口**：初版把「停用 = `win.destroy()`、启用 = 运行时 `build()`」当惰性重建用，实测反复开关悬浮球会**整窗未响应卡死**——运行时现场创建/销毁 WebView2 窗口是主线程长任务，与悬浮球菜单收拢/几何切换等窗口操作在主线程事件循环上交错时 WebView2 controller 创建挂起（剪贴板浮层踩过同款坑，见 `clipboard.rs::init_overlay_window` 注释）。现改为**启动无条件预创建 + 隐藏常驻**，停用只 `hide()`、启用只经 `sync_with_main()` 显隐联动，绝不运行时 build/destroy（`floating_ball.rs::init/apply_enabled`）。全局铁律见 AGENTS.md 关键约定 41。
