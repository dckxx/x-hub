# 工作台 Dashboard — 前端 Design Spec

> 参考图：现代极简「Notion × macOS Bento」风格个人工作台
> 用途：作为「XFactor实验室」个人工作台 / 公众号后台 / 通用 Web 工作台的设计基线
> 版本：v1.1 · 2026-08-13
> ⚠️ 本文档为历史设计基线。当前实现的**唯一基线以 `DESIGN.md` 为准**（玻璃卡片 + 侧栏导航 + Bento 网格，令牌在 `src/style.css`），下述 §2 布局与 §4 组件清单已随 v0.1.8 实现同步更新。
> ⚠️ v0.1.13 起毛玻璃改为「常驻表面静态烘焙 + 瞬态表面真 blur」的性能策略，详见 `DESIGN.md` §7。
> ⚠️ v0.1.13 新增倒计时功能（时长/定时/每天/间隔四种形态，可浮窗为圆形水位小窗），详见 `DESIGN.md` §5 与 `AGENTS.md` 约定 20-22。
> ⚠️ v0.1.15 变更：① 倒计时卡位于**工作台中列上半**（非左列），中列上半为可切换区块 `dashboard_mid_content`（倒计时默认 / Token 统计 / 速记概览 / 待办概览 / 速达数量，设置「工作台」区切换）；② 主题升级为三轴系统（模式 × 预设 × 强调色），品牌强调色由 inline `--accent` 注入；③ 响应式断点改为 1100/960/720；④ 便签为统一玻璃卡（非黄/粉配色）；⑤ Token 用量卡显示今日总量 + 三指标（无迷你趋势/今日调用次数展示）。详见 `DESIGN.md` 与 `AGENTS.md` 约定 26-28。

## 1. 设计理念

| 关键词 | 说明 |
| --- | --- |
| **柔和留白** | 大量浅色背景 + 白卡浮起，弱化分割线，靠空间分层 |
| **Bento 网格** | 卡片大小不一、栅格化拼贴，信息密度可控，避免列表过载 |
| **轻拟物** | 文件夹 / 文档图标保留具象形态，色彩克制，不过分 3D |
| **品牌靛紫** | 主色 `#5B5BF5` 单一聚焦，仅用于强调态（头像、选中、激活 Tab） |
| **无边框主义** | 卡片几乎无 border，靠 `shadow` + `radius` 区分层次 |

```
┌───────────────────────────────────────────────────────────────┐

├────────┬──────────────────────────────────────────────────────┤

│ [速达]  │  │ 系统监视  │ (默认倒计时， │  (整列)      │       │
│ [用量]  │  │ 便签 ×2   │  可切换)      │              │       │
│ …      │  │           │ 提示词百宝箱  │              │       │
│ 设置    │  └───────────┴──────────────┴──────────────┘       │
│ 收起态  │  │          最近使用通栏（跨三列）                │
│ 56px    │  └────────────────────────────────────────────────┘│
└────────┴──────────────────────────────────────────────────────┘
```

> 现状（v0.1.15）：中列上半为 `dashboard_mid_content` 可切换区块（默认倒计时，可切 Token 统计 / 速记概览 / 待办概览 / 速达数量），Token 用量卡不再默认占据中列。

- **两栏 App Grid**：`grid-template-columns: 220px minmax(0, 1fr)`（收起态 `56px`）
- **工作台三列**：`minmax(0,1.2fr) minmax(0,1.8fr) minmax(0,1fr)`，行 `auto minmax(0,1fr) auto`，gap `20px`
- **页面 padding**：右/下 `24px`
- **背景**：`--bg-page`（亮 `#eceff6` / 暗 `#12131b`）
- 首页铺满视口无滚动，卡片内容区内滚动；速记/速达/用量为独立视图

## 4. 组件清单（Component Specs）

> 实现状态：UserCard / NewsBrief / WeatherCard / AppDock 已由 v0.1.8 工作台替换为 **时钟 + 系统监视 + 便签 + Token 用量 + 提示词百宝箱 + 待办 + 最近使用通栏**；文件管理已并入「速达」。以下保留的历史组件仅供参考，实际实现以 `DESIGN.md` 与源码为准。

### 4.1 时钟卡（ClockCard）
- HH:mm 大字号（Display） + 日期星期 caption
- 30s 轮询更新时间
- 工作台左列顶部，高度自适应

### 4.2 系统资源监视器（SysMonitorCard）
- CPU / 内存进度条，2s 轮询（sysinfo 后端）
- 数值显示：CPU %、内存已用/总量 GB、占比
- 工作台左列，位于时钟下方

### 4.3 便签（StickyCard）
- 两张并排（slot 1/2），黄 / 粉配色
- 600ms 防抖自动保存
- 圆角 12px，2-line clamp

> 现状（v0.1.15）：两张便签为**统一玻璃卡**（非黄/粉配色，`--note-yellow-bg`/`--note-pink-bg` 令牌已弃用）；600ms 防抖保留；输入为自适应 textarea（非 2-line clamp）。

### 4.4 待办清单（TodoCard）
```
待办 [待办 3] [已完成 2]          ＋ 添加待办，回车确认
──────────────────────────────
◯ ●  写周报                    🗑
◯ ○  回复邮件                  🗑
◯ ●  安排明日会议              🗑
```
- 头部：标题 + 分段切换（待办 / 已完成），右对齐计数
- 添加行：输入框回车确认；空内容不提交
- 单条：勾选圆钮（完成态品牌色填充 ✓）+ 优先级圆点（**10px 纯色点**，灰/黄/红 = 普通/重要/紧急，点击循环，hover 放大）+ 标题（双击行内编辑，回车或失焦提交，Esc 取消）+ 删除按钮（hover 显现，删除可撤销）
- 已完成项：标题删除线 + 降透明度
- 全局搜索直达：高亮背景 3s，自动滚动到该项

> 现状（v0.1.15）：优先级圆点为 10px 纯色点（无数字），重要/紧急用**柔色变体** `--c-yellow-soft` / `--c-red-soft`（非纯黄/红）；勾选完成态品牌色填充 + 缩放 0.9（无弹回动画）；其余行为与规格一致。

### 4.5 Token 用量卡（TokenStatsCard）
- 三指标（输入/缓存/输出）+ 今日调用次数 + 近 7 日迷你趋势
- 5min 自动刷新 + 手动刷新；监听绿点表示在监听
- 点击进入用量详情视图（UsageView：左趋势/提供商排行 + 右明细分页）

> 现状（v0.1.15）：卡片显示**今日用量总量 + 非缓存/缓存/输出三指标 + 三段分割条 + 监听绿点**，5min 自动刷新 + 手动刷新 + 「查看详情」跳转用量视图；「今日调用次数」与「近 7 日迷你趋势」未在卡片展示（迷你趋势仅存在于用量详情视图）；仅当 `dashboard_mid_content = 'token'` 时该卡出现在工作台中列。

### 4.6 提示词百宝箱（PromptBoxCard + PromptManageDialog）
- 列表卡：标题 + 预览 + 置顶标，点击一键复制并计数
- 管理弹窗：新增/编辑/删除/置顶切换
- 空状态：引导「添加第一条」

### 4.7 最近使用（RecentBar）
- 底部通栏（跨三列），按 `last_launched_at` 排序取前 10
- 图标 + 名称，点击启动；快捷入口跳转速达视图

### 4.8 速达资源管理（Suda）
- 筛选 tabs：全部 / 常用 / 应用 / 网页 / 文件（文件有二级分类）
- 卡片网格：图标（soft 底 + 主色 + ink 文字）+ 名称
- 拖拽导入 exe/lnk（自动解析名称与图标）、右键菜单（打开/编辑/删除）
- 删除可撤销

### 4.9 通用按钮 / Icon Button
- 圆角 8px / pill
- 默认：透明 / 浅灰 hover
- 激活：主色填充

## 5. 交互细节

| 动作 | 反馈 |
| --- | --- |
| Tab 切换 | 选中态滑动过渡 200ms ease-out |
| 文件夹 hover | transform translateY(-2px) + shadow 200ms |
| 待办勾选 | 品牌色填充 + 缩放 0.9 弹回 180ms |
| 优先级圆点 | hover 放大 1.35 |
| 便签 hover | 旋转回正 200ms |
| 拖拽文件 | 全屏遮罩 + 透明度 0.7 + 阴影加深 |
| 新建按钮（+） | 旋转 45° 变 ✕ 200ms |

键盘快捷键建议（v2）：
- `g f` 跳文件、`n` 新建便签、`?` 打开快捷键面板

> 现状（v0.1.15）：已实现 —— 待办勾选品牌色填充 + 缩放 0.9、优先级圆点 hover 放大、拖拽导入全屏遮罩、卡片 hover 上浮、按钮按下 scale(0.96)、删除撤销 toast；未实现 —— Tab 选中态滑动过渡（侧栏为 150ms 背景过渡）、便签 hover 旋转回正、新建按钮（+）旋转 45° 变 ✕。

## 6. 响应式

| 断点 | 行为 |
| --- | --- |
| ≥1280 | 三栏完整布局 |
| 1024–1279 | 中栏收为 360px；右栏 `1fr` 自适应 |
| 768–1023 | 改为两栏：左栏 + 右栏，中栏折到下方 |
| <768 | 单列堆叠；Dock 收缩为 5 项；便签单列 |

> 现状（v0.1.15）：断点为 **1100 / 960 / 720** —— ≤1100 收紧工作区 padding；≤960 三列折两列（待办折到左列下方）；≤720 单列堆叠 + 侧栏强制恢复文字导航。

触摸目标：≥44×44px（移动端）。

## 7. 无障碍（A11y）

- 对比度：正文 ≥4.5:1，UI ≥3:1（已在 token 中校准）
- 焦点环：使用 `--shadow-focus`，永不去除
- ARIA：待办分段用 `role="tablist"`，Tab 用 `role="tablist"`
- 减少动效：`prefers-reduced-motion` 时关闭 transform，仅保留颜色过渡
- 键盘可达：所有可点击元素 `tabindex=0`，回车触发

## 8. 实施 Checklist（前端落地顺序）

> 当前版本（v0.1.8）已按此清单落地并迭代；清单保留为演进参考。

1. **设计令牌**：建 `tokens.css`（现为 `src/style.css` CSS 变量），导入 Tailwind / 全局
2. **基础容器**：App Shell 两栏 Grid（侧栏 + 主区）
3. **侧栏导航 + 主题切换**（工作台/速记/速达/用量）
4. **工作台**：时钟 + 系统监视 + 便签（左列）
5. **Token 用量卡 + 提示词百宝箱**（中列）
6. **待办清单**（右列整列）
7. **最近使用通栏**（底部跨列）
8. **独立视图**：速记（笔记+标签）、速达（资源管理）、用量（详情双栏）
9. **响应式断点适配**
10. **交互动效（hover / 切换）+ 弹窗焦点陷阱**
11. **A11y 收尾 + 暗色模式（token 已对齐）**
