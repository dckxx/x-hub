介绍
一键格式化、校验、压缩 JSON。支持大文件流式处理，格式化结果可折叠，路径点选提取字段，出错时精确定位到行号。
使用说明
1. 打开扩展，粘贴或拖入 JSON 文本。
2. 点击「格式化」自动缩进，或「压缩」转单行。
3. 出错时右侧定位到首个语法错误位置。
4. 点字段路径即可复制对应值。
