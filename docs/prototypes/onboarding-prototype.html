功能模块

工作台

时钟/天气/系统资源/便签/待办/提示词的自由编排主页。
在布局编辑器里拖拽卡片、调整宽高，自定义你的首页。
设置 → 工作台 → 布局编辑器

速记

纯文本 + Markdown 双模式笔记，自动保存。
用标签归类，顶部可切换预览/编辑。
无需配置 · 侧栏「速记」进入

速达

应用/网页/文件三类资源合一，一键启动。
把 exe 拖进来自动提取图标；也可扫描已装应用批量导入。
设置 → 常规（数据与导入）

剪贴板

自动记录文本/图片/文件历史，一键回贴。
按 Ctrl + ` 唤起浮层。
设置 → 剪贴板（记录开关 / 清理）

倒计时

时长/定时/每天/间隔四种模式，后台到点通知。
可浮起为透明水罐浮窗，置顶显示。
设置 → 常规（提示音开关）

AI 对话

OpenAI 兼容流式对话，支持 DeepSeek/Ollama 等。
按 Ctrl + Shift + K 唤起，可停靠四方位。
设置 → AI助手（供应商/模型/Key）

扩展

安装第三方扩展（module/视图/浮窗），扩展桌面能力。
扩展中心按 GitHub 地址下载 zip 安装。
设置 → 扩展（权限与卸载）

设置

10 个分类管所有偏好：外观/快捷键/AI/数据/备份。
改主题三轴、全局快捷键、数据路径、开机自启动。
侧栏底部「设置」进入
