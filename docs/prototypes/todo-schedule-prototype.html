待办优化 交互原型 v1

  1. 截止日期：行内徽标（逾期红 / 今天橙 / 明天品牌色 / 其他灰），点击弹出日历 + 时间设置；只选日期不选时间 → 当天 23:59 截止。
  2. 提醒：同一弹层内开关，可独立于截止时间，到点弹系统通知 + Toast。
  3. 子待办：父条目下方缩进列表，行尾 「+」 或 Shift+Enter 添加；父条目显示完成进度。
  4. 排序：待办分组 = 逾期 → 今天 → 有日期 → 无日期，组内沿用现有规则。
逾期已过截止，最优先
今天当天截止
明天近一两天
3月9日更远日期

可试：点徽标改日期、点 + 加子待办、双击改内容、点圆点切优先级、删父待办级联删子。
原型仅演示交互，不接真实数据。
