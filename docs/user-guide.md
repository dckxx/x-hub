# x-hub 使用说明

> 适用版本：v0.9.4（Windows 桌面版）
> x-hub 是一款**本地优先**的个人效率工作台：Bento 卡片式工作台、待办、速记、速达（应用/网页/文件快捷启动）、AI 助手、剪贴板历史与扩展系统。所有数据默认保存在本机，不上传云端。

**阅读约定**

- 「设置 → 外观 → 主题模式」表示：点击侧栏左下角「设置」→ 左栏选择「外观」大类 → 找到「主题模式」这一项。
- 「右键」= 点鼠标右键；「悬停」= 鼠标停在元素上不点。
- 界面按钮文案均用引号原样标注，如「新建待办」。

## 1. 认识 x-hub

### 1.1 界面总览

| 区域 | 说明 |
|---|---|
| **标题栏** | 顶部通栏。按住空白处可拖动窗口；双击空白处最大化/还原。右侧按钮从左到右：**全局搜索**、**AI 对话**、**窗口置顶**（图钉，可切换）、**最小化**、**最大化/还原**、**关闭** |
| **侧栏** | 左侧竖条，默认收起为 56px 图标态，悬停图标约半秒弹出名称气泡。导航项自上而下：**工作台 → 待办 → 速记 → 速达 → AI 助手**；其下是固定到侧栏的扩展图标；底部固定区为 **扩展中心** 与 **设置**（左下角） |
| **主区** | 当前视图的内容区 |
| **系统托盘** | 屏幕右下角图标，程序关闭窗口后仍在此驻留 |

### 1.2 窗口操作与退出

- **拖动窗口**：按住标题栏空白处拖动。
- **置顶**：点标题栏图钉按钮，窗口将保持在最前。
- **关闭按钮 ≠ 退出**：点「关闭」是最小化到系统托盘（首次关闭会有提示）。彻底退出请**右键托盘图标 → 退出**。
- **托盘图标**：左键单击 = 显示/隐藏主窗口；右键菜单 = 显示主窗口 / 隐藏主窗口 / 重启 / 退出。

### 1.3 数据存在哪里

- **标准版**：`C:\Users\你\AppData\Roaming\x-hub`（可在 设置 → 数据与关于 → 数据 → 「更改」迁移，见 §13）。
- **便携版**：exe 同级的 `data` 文件夹（不可迁移）。
- 数据库、笔记图片、图标、壁纸、备份都在该目录下；卸载软件不会删除数据目录。

## 2. 全局快捷键

系统级注册，**任何应用中按下都生效**。全部在 **设置 → 常规 → 快捷键** 中管理。

| 功能 | 默认按键 | 作用 |
|---|---|---|
| 全局快捷键（主窗显隐） | `Ctrl+Shift+Space` | 显示 / 隐藏主窗口 |
| 剪贴板呼出 | `` Ctrl+` `` | 唤起剪贴板历史浮层（见 §8） |
| 搜索呼出 | `Ctrl+K` | 唤起全局搜索（见 §9） |
| AI 对话呼出 | `Ctrl+Shift+K` | 唤起 AI 对话（抽屉或独立窗，见 §7.1） |
| 速记呼出 | `Ctrl+Shift+N` | 唤起主窗 → 切到速记 → 新建一篇笔记 |

**改键**：点击对应行的输入框直接按下新组合键，或点「录入」按钮进入录制态后按键。保存前会自动检查冲突：与其它快捷键撞车会点名提示；被其它程序占用的按键会提示「可能正被其它程序占用」。

**临时禁用**：每行右侧有开关。禁用 = 注销系统热键但**保留键值**，重新打开即恢复，不必重新录制。

## 3. 工作台

工作台是一块自由编排的 Bento 卡片仪表盘，所有卡片的位置、大小、形态都由你决定。

### 3.1 布局编辑器（核心操作）

**进入**：设置 → 工作台 → 「自定义布局」→「打开编辑器」；若工作台已被清空，主界面也会出现「自定义布局」按钮。完成后点「确认」自动回到工作台。

画布为 12 列 × 15 行的格子棋盘，所看到的即真实工作台的等比缩印（时钟、天气直接挂真实组件）。

**基本操作**

- **添加卡片**：从左侧模块库按住条目拖入画布。新卡片按该形态的**最小尺寸**落位；目标位置被占时自动向下找最近的空位。多形态模块（时钟/天气）先在条目上点形态芯片选好形态再拖。
- **移动**：在画布内拖动卡片换位，放哪落哪。
- **调整大小**：拖卡片右下角的小角标。会被钳制到该形态的最小尺寸；与其它卡片重叠时拒绝并回退。
- **删除**：悬停卡片点右上角「×」，或把卡片拖回左侧库区。
- **切换形态**：悬停多形态卡片点「⇄」，浮层中每项带缩略图、名称与尺寸标记（✓ 当前格子放得下 / ⚠ 需要更大格子）。切换后格子不够会自动补足。
- **自定义标题**：悬停卡片点「Aa」：可改标题（最长 24 字，留空恢复默认）、勾选「不显示标题行」隐藏表头。
- **适配徽标**（卡片左下角，悬停显示；勾选顶部「填充审计徽标」后常显）：
  - 绿「正好铺满」= 等于推荐尺寸；黄「紧凑可读」= 够用但没到推荐；蓝「弹性空间」= 比推荐还大；红「低于最小」= 内容会被裁切，建议拉大。
- **系统资源卡专属**：悬停后控制钮排里有滑杆图标，直接打开显示设置（见 §3.5）。

**顶部按钮**

- 「清空」：清掉画布；「推荐布局」：一键铺回内置 9 模块推荐模板。
- 「存为默认」：把当前画布保存为默认快照，**立即生效**，之后点「取消」也不会丢。
- 「恢复默认」：把画布铺回快照——在编辑器内只是回到草稿，**还要点「确认」才真正生效**。
- **「确认」= 保存并返回**；不点确认就离开 = 整体放弃本次改动。

**两条实用规则**

- 从布局删卡**不删数据**：便签、倒计时、自定义速达的内容都保留，重新拖入即恢复。
- 倒计时卡从工作台移除后，非浮窗的倒计时会自动暂停（见 §3.11）。

### 3.2 时钟卡（三形态）

| 形态 | 内容 | 最小/推荐尺寸 |
|---|---|---|
| 大时钟 | 时分秒 + 日期星期 + 右上角天气 + 底部语录 | 3×3 / 4×3 |
| 今日阴阳历 | 时:分 + 阳历 + 农历 + 干支生肖 | 2×2 / 3×3 |
| 极简时间 | 大号时:分 + 小号秒数 | 2×1 / 2×2 |

- 形态在布局编辑器中切换（§3.1）。
- 大时钟底部的**语录可点击**换一条；在 设置 → 工作台 →「时钟卡片语录」填入自定义文案（≤50 字）后固定显示、不再更换。「名言来源」可选在线（联网随机、离线回退本地语料）或仅本地。

### 3.3 天气卡（两形态）

- **简版**（2×1 / 2×2）：图标 + 温度 + 天气 + 城市，一行横排。
- **详情版**（3×3 / 4×4）：头部同上 + 体感温度 / 湿度 / 风速 / 天气状况四格。
- 数据来自 Open-Meteo 在线接口，**需开启联网开关**（设置 → 功能 → 联网）；无网时天气自动隐藏。
- **城市设置**：设置 → 功能 → 联网 →「天气城市」：输入城市名（内置全国主要城市）点「设置」，或点「自动定位」（按 IP 定位，可能不准）。

### 3.4 系统资源卡

- 显示 CPU / 内存 / 网络等指标，进度条 ≥85% 变橙红警告；标题旁绿色呼吸点表示采集中（前台 2 秒刷新、失焦 5 秒、滚出视野暂停）。
- 可显示 6 项指标：**上传/下载**（一行 ↑↓ 数值）、**CPU**、**内存**（含已用/总量小字）、**总网速**、**CPU线程**、**总流量**（本应用启动以来累计，重启归零）。
- **自定义显示项与排序**：入口在**布局编辑器**中该卡片的控制钮排（滑杆图标）→「系统资源 · 显示设置」：勾选显示项、↑↓ 调整顺序、「恢复默认」回到 上传/下载 + CPU + 内存。点「确定」才保存，取消不落盘。
- 格子太小时内容会被裁切——拉高卡片即可。

### 3.5 便签 1 / 便签 2

- 直接在卡上打字，**600ms 后自动保存**，无需任何按钮。
- 表头右侧按钮：未脱离时点「脱离为悬浮便签」→ 变成桌面独立小窗（可拖动、图钉置顶、× 关闭）；已脱离时按钮变为「聚焦浮窗」，点击把浮窗调到前台。
- 关闭浮窗时：内容为空直接删除；另一个便签槽还空着会询问「还原到主面板？」；两个槽位都有内容则只能删除或取消。
- 删掉工作台上的便签卡不删内容，重新拖入同号槽位（便签 1 / 便签 2）内容还在。

### 3.6 日记卡（随手记）

- 宽幅输入框，**Enter 保存、Shift+Enter 换行**（输入法组词中的回车不会误触发）。
- 内容存入速记的「日记」文件夹（没有会自动创建），笔记标题为保存时刻（如 `2026年10月24日 15:30:02`）。
- 保存成功自动清空输入框；失败保留原文并提示重试。

### 3.7 待办卡（工作台）

- 顶部输入框：输入后**回车即建**；输入含 ≥2 个序号的文本会自动拆成多条（见 §4.4）。
- 「待办 / 已完成」两个页签切换；标签筛选行按标签过滤。
- 分组显示：置顶 → 逾期 → 今天 → 有日期 → 无日期（只显示非空组）。
- 右上角「待办浮窗」按钮打开独立小窗（见 §4.10）。
- 行上操作与待办视图完全一致（见 §4.6）；卡片内点日期徽标会弹出快捷排期层（今天/明天/下周一 + 迷你月历 + 提醒开关）。

### 3.8 日历卡（只读）

- 月历上标出待办分布：格子里的 chip 未完成=品牌色、逾期=红色、已完成=灰底删除线，周期待办显示为虚线边框的虚拟实例；放不下的折叠成「+N」（悬停格子看完整清单）。
- **点整卡任意处进入待办视图**。翻页只有上/下月。

### 3.9 三张概览卡

| 卡片 | 内容 | 跳转 |
|---|---|---|
| 速记概览 | 笔记数 / 标签数 / 最近编辑的一条（相对时间） | 右上角 → 去速记 |
| 待办概览 | 完成率圆环 + 「还有 N 项待完成」+ 总数/今日新增/已完成 | 右上角 → 去待办 |
| 速达数量 | 资源总数 + 应用/网页/文件计数与比例条 | 右上角 → 去速达 |

### 3.10 倒计时卡与圆形浮窗

**新建**：卡片表头右侧「＋」。弹窗中填名称，四类页签任选：

1. **时长**：填分钟数（1–1440），从现在起倒数（如番茄钟 25 分钟）。
2. **定时**：选未来某个日期 + 时刻。
3. **每天**：填每天的时刻（默认 15:00，当天已过则从明天开始）。
4. **间隔**：每 N 分钟循环提醒。

**列表操作**：悬停条目浮出 暂停/恢复（⏸/▶）、浮窗显示/收起、删除；已结束条目置灰只留删除。数量上限 6 个。

**到点行为**：右下角弹系统通知卡 + 主窗 toast；**提示音默认关**，可在 设置 → 工作台 →「倒计时到点提示音」开启。应用退出/休眠期间错过的提醒（超 5 秒）不补发，每天/间隔类型自动顺延到下一轮。

**圆形浮窗**：水位高度 = 剩余比例，双层波浪动画；悬停显示暂停/收起按钮，按住可拖动，位置记忆。一次性倒计时到点自动收窗。

### 3.11 提示词卡

- **点整行复制全文**（toast 提示 + 复制计数 +1）；列表排序 = 置顶优先 → 复制次数多 → 最近复制。
- 表头右侧「管理提示词」打开管理弹窗：左上「＋」新增（标题+内容必填），行悬停可 置顶 / 编辑 / 删除（删除后 toast 带「撤销」）。
- 表头右侧「提示词浮窗」打开独立小窗（可拖动、置顶），内容与主窗实时同步，同样点击复制。

### 3.12 最近使用（通栏）

- 展示最近启动过的速达资源图标（按最近启动排序，最多 10 个），点图标即启动；格子越大显示越多。
- 空态有「去速达添加」按钮。

### 3.13 自定义速达 1–4（suda1..suda4）

把任意一批速达资源钉在指定卡片上：

1. 点卡片右上角的设置钮「配置内容」。
2. 顶部选内容来源（单选）：
   - **手动挑选**：搜索并勾选任意资源，**勾选顺序即展示顺序**；
   - **应用 / 网页 / 文件**：自动展示对应大类的全部资源，随速达页增删联动；
   - **小类**：单选一个小类，展示该小类（含子级）全部资源。
3. 点「保存」。取消或点遮罩关闭则不保存。

卡片条目点击即启动。删卡不删配置，重新拖入同槽位内容还在。

## 4. 待办

### 4.1 入口

- **侧栏「待办」**：完整视图——宽窗为左列表 40% + 右日历 60%，窄窗自动变单栏并用「列表 / 日历」按钮切换。
- **工作台「待办」卡**：快速添加 + 分组列表（§3.7）。
- **工作台「日历」卡**：只读月历（§3.8）。
- **待办浮窗**：独立小窗（§4.10）。

### 4.2 新建待办

- 待办视图右上角「+ 新建待办」；
- 日历里双击某天，或「当天明细」里的「加待办」（自动预填那天 23:59 为截止）;
- 工作台待办卡 / 待办浮窗顶部输入框回车。

### 4.3 编辑弹层字段

双击待办标题、或点行进入编辑。字段一览：

| 字段 | 说明 |
|---|---|
| **标题** | 必填，回车可直接保存 |
| **描述** | ≤200 字，支持轻量 Markdown；悬停列表中的行可看完整描述。要打勾的清单请用子待办 |
| **标签** | 待办专属的一套标签（与笔记标签互不影响）；色点胶囊多选，「+ 新建标签」直接建 |
| **置顶** | 勾选后固定在列表最顶部「置顶」区，与日期无关 |
| **周期** | 见 §4.5 |
| **截止** | 应用内日历 + 24 小时制时间；快捷胶囊：今天 / 明天 / 本周六 / 下周一 / 本月末 / 下月初（都落在当天 23:59）；右侧 × 清除 |
| **提醒** | 同款时间字段；快捷胶囊：同截止 / 提前 1 小时 / 提前 1 天 / 今天 09:00 / 明天 09:00 |
| **提醒方式** | 设了提醒才出现：弹窗 + 声音 / 仅弹窗（默认） / 仅声音 / 静默 |

编辑态底部左侧红色「删除」；点遮罩不关闭弹层，防误触丢内容。

### 4.4 序号列表拆多条

在工作台待办卡 / 待办浮窗的添加框里，输入含 ≥2 个序号的文本回车，自动拆成多条并提示「已拆成 N 条待办」：

```
1. 买菜 2. 寄快递 3. 复盘   →  拆成 3 条
```

支持 `1.` `1、` `1)` 等写法；小数（如 `3.14`）不会被误拆。

### 4.5 周期待办

周期一行胶囊单选：**不重复 / 每天 / 每个工作日 / 每周 / 每月 / 每年 / 自定义…**

- **每周**：出现「一 二 三 四 五 六 日」多选；
- **自定义**：「每 [1-99] [天/周/个月/年]」；
- **每月**：选「每月第几天」（1–31，超出当月天数取最后一天）或「每月第几个星期几」；
- **结束条件**：永不结束 / 到某日结束 / 共 N 次；下方蓝色「规则：…」实时预览，不满足条件有红字提示（如每周一个都没选）。
- 前提：周期待办需要先设置「截止」时间作为重复基准。
- **勾选 = 完成本轮**：不进已完成列表，日期自动滚到下一轮（toast 提示「已滚到 …」，可撤销）；规则用尽转回普通一次性待办。逾期未完成不补历史。

### 4.6 列表行操作

- **完成**：点行首圆圈。勾父待办时若有未完成子项，先确认「确认并勾选子项」。
- **优先级**：行首圆点（灰=普通 / 黄=重要 / 红=紧急），点击循环切换。
- **置顶**：置顶项标题前有图钉，点图钉取消置顶。
- **徽标**：
  - 日期徽标：逾期红「逾期 M月D日」/ 今天橙 / 明天品牌色 / 更远灰；**点击**打开排期层（工作台卡）或编辑弹层（待办视图）；
  - 提醒徽标：绿色「提醒 HH:MM」，点击弹菜单快捷切换提醒方式；
  - 周期徽标：蓝色只读，悬停看规则详情与累计完成次数。
- **子待办**：悬停行出现「+」，输入后回车添加（仅一层，不可嵌套）；父行显示 n/m 进度条；子行可勾选、双击编辑、删除、组内拖拽，也可跨父拖挂。
- **行内编辑**：双击标题文字，回车保存、Esc 取消、失焦自动保存。
- **拖拽排序**：按住行拖动，出现品牌色插入线。顶级行仅在同一分组内上下排序（且仅「未完成」视图开放）；子待办可同父重排或跨父拖挂。
- **删除与撤销**：悬停点垃圾桶；删除父条目会级联删除子待办，toast 带「撤销」按钮，5 秒内点击可整体恢复。

### 4.7 待办视图工具栏

- **范围筛选**：今天 / 本周 / 本月 / 全部（默认本周）。置顶、逾期、无截止的条目在任何范围下都常显。
- **已完成切换**：「看已完成 / 看未完成」。
- **标签筛选**：一行标签胶囊（带未完成计数），点选为多选匹配；胶囊悬停「×」可删除标签（会从所有待办上摘掉，不可撤销）。
- **分组**：置顶 → 逾期 → 今天 → 本周 → 本月 → 以后 → 无日期，只显示非空组。

### 4.8 月 / 周日历

- 每格最多直接显示 2 个 chip，多余的折叠成「…+N」（点击选中该天）；实线=未完成、红色=逾期、灰底删除线 ✓=已完成、**虚线边框=周期虚拟实例**（点击会提示去编辑弹层改周期规则）。
- **点日期格**选中该天，下方出现「当天明细」；**双击**格子在那天新建待办；**点 chip**打开编辑。
- **拖拽改期**：把未完成的实心 chip 拖到其他日期，截止改到该天并保留原时分（已设提醒同步平移）。
- 逾期日期整格淡红底，全部完成后自动消退。「月 / 周」按钮切换，‹ › 翻页，「今天」回到当前。

### 4.9 提醒与通知

到点后按该条的提醒方式生效：**仅弹窗**（右下角通知卡 + 主窗 toast）、**弹窗 + 声音**、**仅声音**、**静默**（只标记已触发）。每条提醒只触发一次；应用退出/休眠错过的（超 5 秒）不补发。

### 4.10 待办浮窗

- 打开：工作台「待办」卡右上角「待办浮窗」按钮，再点一次关闭。
- 无边框小窗：按住标题栏或空白区拖动；四边四角可拉伸；标题栏图钉 = 窗口置顶。
- 内容：添加框（支持序号拆分）+ 未完成平铺列表；行上交互与卡片一致。差异：无排期弹层、删除无撤销、顶级行不支持拖拽排序。

## 5. 速记

### 5.1 界面

侧栏「速记」进入（全局快捷键 `Ctrl+Shift+N` 可随时唤起并新建）。两栏布局：

- **左栏 = 文件夹树**（唯一导航面）：树根即「未归类」笔记；树头按钮从左到右：搜索、全部展开/收起、**新建笔记**、**新建目录**、**回收站**。
- **右栏 = 编辑器**。

选中是单一模型：点文件夹浏览（编辑器回空态），点笔记打开编辑；点树空白处取消选中回到树根。

### 5.2 文件夹树操作

| 操作 | 方式 |
|---|---|
| 新建笔记/目录 | 树头按钮（跟随当前选中文件夹，未选中落根目录）；文件夹行悬停「+」就地建子目录；树空白处**右键** → 新建笔记/新建目录 |
| 重命名 | 行悬停铅笔 / 右键「重命名」/ 选中后按 `F2` |
| 删除文件夹 | 行悬停垃圾桶 / 右键 / 选中后按 `Delete`。弹确认框：**其中的笔记与子文件夹会上移一级，不会丢失** |
| 拖拽移动 | 笔记拖到文件夹行 = 移入；拖到树头/底部空白 = 回根目录。文件夹拖到另一文件夹行 = 变为其子文件夹（不能拖进自己的后代）；贴近行上下缘是同层排序 |
| 笔记排序 | 拖到另一笔记行的**上/下边缘（约 25% 区域）**出现插入线，松手即组内排序；未排序的笔记按创建时间正序垫底（旧在上、新在下） |
| 自定义图标 | 编辑器里标题左侧笑脸图标选 emoji（右键清除），显示在树行行首 |
| 内置「剪藏」夹 | 网页剪藏专用，不可改名/删除，可导出 |

新建笔记后没写任何内容就切走，会被自动清理，不产生「无标题笔记」垃圾。

### 5.3 搜索与标签筛选

- 点树头搜索图标展开搜索框（失焦且无词时自动收起）。
- 直接输入 = **跨全部文件夹的全文搜索**（标题+正文），结果平铺并标注所在文件夹路径。
- 输入 `#` 进入标签筛选：下拉列出所有标签（带笔记数），可用方向键+回车选择；下拉里右键标签可重命名/删除。`#标签名` 精确匹配即进入该标签的筛选态。
- `Esc` 或清空即退出搜索态。

### 5.4 回收站

- 树头回收站图标进入，平铺已删笔记。
- 行悬停：「还原」（回到原处）/「永久删除」（不可撤销）；树头有「一键清空回收站」（红色按钮，确认后全部永久删除）。
- 删除笔记均为软删（先进回收站）。回收站保留时长在 设置 → 数据与关于 → 数据 →「回收站保留天数」（默认永久保留）。

### 5.5 编辑器

- **四种模式**（右上角图标切换，按用户记住、不按笔记）：**实时预览**（所见即所得）/ **分屏预览**（左源码+右实时预览）/ **源码** / **仅预览**（只读）。
- **标题**：顶部输入框（≤80 字）。空标题或仍是「无标题笔记」时，会从正文首行自动派生；你一旦改过就不再接管。
- **自动保存**：停止输入 600ms 后自动落盘；右下角显示「编辑中… / 已保存 时间」。
- **斜杠菜单**：行首输入 `/` 呼出插入菜单（标题、列表、代码块、表格、公式、图片等，已汉化）。`#`、`>`、`-`、`1.`、`---`、`- [ ]` 加回车可快速转成对应结构。
- **粘贴自动成码**：从别处复制的裸代码（没有围栏标记）粘贴进来会自动变成代码块；代码块右上角有「复制」按钮。
- **标签行**：底栏左侧，「+」输入回车创建（≤20 字），胶囊上的 ✕ 移除。
- **来源链接**：剪藏笔记在标题下方显示原文出处，点击用系统浏览器打开。

### 5.6 图片

- **插入**：直接**粘贴** / **拖入**正文 / 点击图片块**上传**；支持 png/jpg/jpeg/webp/bmp/gif，单张 ≤10MB，自动落盘到本地笔记图片库，同内容自动去重。
- **调整宽度**：悬停图片，右下角出现把手，拖动即可；缩窄后多张图可并排；拖回接近满宽恢复响应式。
- **图注**：图片下方可输入说明文字。
- **预览**：点击图片打开全屏灯箱（Esc / 点遮罩关闭）。
- **复制图片**：灯箱右上角「复制图片」、图片**右键**「复制图片」、或选中图片 Ctrl+C——复制的是真实位图，可直接粘进聊天/文档/画图。

### 5.7 双链

- 正文中输入 `[[` 弹出笔记标题补全（显示标题+目录，↑↓ 选择回车插入）。
- 点击双链直接跳转到对应笔记；`http(s)` 外链用系统浏览器打开。
- 标题右侧 **Waypoints 图标**开关右侧全高「双链面板」：**入链**（谁引用了本篇）/ **出链**（本篇引用），点击跳转；引用了还不存在的标题会显示为未解析条目，创建后自动接上。
- 给笔记**改名**时，全库引用它的 `[[旧标题]]` 会在同一事务里自动改写，不断链。

### 5.8 一键美化与 AI 深度整理

- **一键美化**（✨ Sparkles 按钮，四模式可用）：确定性排版整理——统一列表标记、标题空行、清理行尾空白、中英文之间加空格等；一步可 Ctrl+Z 还原。已很规整时提示「格式已经很规整了」。
- **AI 深度整理**（🪄 WandSparkles 按钮）：**有选中文字则只整理选中片段，否则整理全文**。点击后弹层流式预览，底部三个按钮：取消 / 复制 / **应用到笔记**（片段时为「替换选中片段」）；关闭弹层 = 放弃。模型把图片语法改坏会自动修回。
  - 使用的模型在 **设置 → 功能 → 速记 →「AI 深度整理模型」** 配置：默认「自动」（开了平台额度且已登录就走平台，否则用你的默认模型）；也可指定平台负载切换或某个具体模型。
  - 注意：笔记内容会发送给你配置的模型（弹层顶部会注明）。

### 5.9 导出

- **单条/整夹导出**：在左栏**右键笔记或文件夹 →「导出…」**，格式三选一：**Markdown / HTML / PDF**。整夹导出含子文件夹，有进度可取消。
- **整库导出 / 导入**：设置 → 数据与关于 → 数据（见 §13）。导出为按文件夹组织的 Markdown（含图片）；导入仅支持 x-hub 自己导出的产物。

## 6. 速达

应用、网页书签、文件/文件夹的统一快捷启动器。

### 6.1 界面与 Tab

顶部五个大 Tab：**全部 / 常用 / 应用 / 网页 / 文件**。

- **常用** = 有启动记录的资源按最近使用倒序（此 Tab 不支持手动拖拽排序，其他 Tab 可长按卡片拖动排序）。
- 头部还有：图标大小下拉（小/标准/大/特大）、批量管理、三个扫描导入按钮、「修复图标缓存」、「+ 添加」。

### 6.2 小类筛选

- 在「应用 / 网页 / 文件」Tab 下出现小类筛选行：第一个是「全部」，然后是「未归类」和各小类；带 ★ 的是**默认小类**（新增资源未指定时自动归入）。
- 小类名支持 `/` 层级（如「开发/前端」，浏览器书签导入会自动带层级）：筛选行只显示顶层，带 ▸ 的悬停/点开级联菜单逐级下钻；**选中某级 = 展示该级及所有子级的资源**。
- 切换大 Tab 时筛选自动重置。

### 6.3 分区（「全部」Tab 的自定义分组）

分区跨大类混居，只管「全部」页的视觉成组；与 6.2 的小类互不影响。**一个分区都没建时，「全部」保持平铺**。

- **新建**：Tab 行右侧「＋ 分区」（自动命名「分区 N」并立即进入改名）。
- **改名 / 排序 / 删除**：双击分区名改名；分区头「⋯」或右键菜单：图标大小（分区级覆盖）、重命名、上移、下移、删除（成员移入「未分区」，可撤销）；按住分区头拖动调整顺序。
- **调框大小**：分区框右下角斜纹把手拖动，按整卡吸附；设定值是下限，内容多了会自动撑高。
- **资源进分区**：长按卡片拖到目标分区；或右键资源 →「移动到分区」。尾部虚线「未分区」块是拖出分区的落点。

### 6.4 添加资源的五种方式

1. **手动添加**：右上角「+ 添加」（在某大类 Tab 且筛了小类时，弹窗自动预选类型和小类）。
2. **拖拽导入**：把 exe / lnk / 网页文件 / 任意文件 / 文件夹拖进窗口任意位置 → 出现「释放以添加」遮罩 → exe/lnk 自动解析名称与图标 → 弹出预填好的添加弹窗，确认「添加」入库。
3. **扫描已安装应用**：列出本机安装的应用（含 Microsoft Store 应用），搜索过滤、全选/全不选，已添加的置灰，点「添加选中（N）」。
4. **扫描桌面**：只扫桌面一层；「加入速达只记一条快捷方式，不动原文件」；可选「导入后清理桌面快捷方式」（只删对应的 .lnk/.url）。
5. **导入浏览器书签**：支持 Chrome / Edge / Brave / Chromium，树形勾选；默认按浏览器文件夹层级自动建小类、按网址去重。

### 6.5 编辑 / 删除 / 批量

- 悬停卡片右上角「编辑（铅笔）/ 删除（垃圾桶）」，或右键。删除只删条目不动磁盘文件，可撤销。
- **批量管理**（头部 ListChecks 图标）：点卡片勾选、全选/全不选、批量删除（二次确认，可整体撤销）。配合筛选可「筛出一类 → 全选 → 删」。

**编辑弹窗字段**：

| 字段 | 说明 |
|---|---|
| 类型 | 本地程序 / 网页书签 / 文件·文件夹（三胶囊） |
| 名称 | 必填，≤80 字 |
| 图标 | emoji 或本地图片文件（ico/png/jpg/webp）；程序自动提取图标；网页自动抓 favicon |
| 目标 | 程序路径（Store 应用为 `shell:AppsFolder\...`）/ 网址 / 文件路径；只建链接不动源文件 |
| 启动参数 | 仅本地程序，如 `--new-window` |
| 小类 | 单选；可「未归类」 |
| 分区 | 下拉（建过分区才出现） |
| 说明 | ≤120 字，悬停卡片时显示 |
| 备注 | 左侧前缀名可改（如「账号密码」），右侧值**密文圆点显示**，小眼睛切明文；**经系统级加密保存在本机**，其它系统账户读不到 |

### 6.6 启动与打开方式

- **单击卡片即启动**；程序运行中名称左侧显示小绿点（再次点击会尝试唤起已开窗口）。
- **网页的打开方式**（右键单个资源临时选择）：
  - **在内嵌面板打开**：主窗速达视图内嵌真浏览器子视图（见 §6.8）；
  - **在独立窗口打开**：带多标签的应用内浏览器窗；
  - **用某浏览器打开**：列出本机已装浏览器（Chrome/Edge/…）。
  - 全局默认在 **设置 → 功能 → 速达 →「网页默认打开方式」**（内嵌面板 / 独立浏览器窗口 / 系统默认浏览器）。
- **以管理员身份运行**：仅程序类，右键选择，弹 UAC 确认（Store 应用不支持）。
- **文件/文件夹**：单击用系统默认方式打开；右键「打开文件所在位置」在资源管理器中定位。
- `smb://`、`ftp://` 类地址可作为网页资源保存，点击交给系统处理。

### 6.7 图标维护

- 拖入/选择 exe、lnk 自动提取高清程序图标；网页后台自动抓 favicon。
- 图标发糊或损坏：头部「**修复图标缓存**」按钮全量自愈（手动导入的图标与 favicon 不受影响）。
- 手动换图标：编辑弹窗「图标」字段。

### 6.8 应用内浏览器

- **内嵌面板**（主窗内）：工具栏 = 后退 / 前进 / 重新加载 / 地址栏（回车跳转，自动补 https） / 在独立窗口打开 / 用系统浏览器打开 / 关闭。工具栏显示与否由 设置 → 功能 → 速达 →「内嵌面板显示工具栏」控制（默认隐藏，网页占满面板）。网页里的新窗口请求在面板内原地打开。
- **独立浏览器窗口**：顶栏含标签页条（≥2 个页面时出现；点 × 或**中键**关标签）与工具栏；新弹窗自动落成新标签。

## 7. AI 助手

### 7.1 三种形态与入口

| 入口 | 行为 |
|---|---|
| 侧栏「AI 助手」 | 完整视图：左 260px 会话列表 + 右对话区 |
| 标题栏 AI 按钮 / `Ctrl+Shift+K` | 弹出主窗内嵌抽屉；开了独立窗模式则唤起独立小窗 |
| 悬浮球「AI 对话」 | 同上分流 |

- **内嵌抽屉**（默认）：从主窗边缘滑出，方位在 设置 → AI 助手 → 面板 →「AI 对话面板位置」（右/左/上/下）；拖内边手柄调尺寸；「AI 对话面板透明度」50–100%；点抽屉外任意区域收起。
- **独立窗口**：设置 → AI 助手 → 面板 → 开启「以独立窗口打开 AI 对话」。玻璃小窗，标题栏可拖动、图钉置顶；「关闭」只是隐藏，下次唤起秒开。两种形态互斥。

### 7.2 模型配置

**方式一：x-hub 平台额度（无需自己的 API Key）**

- 路径：设置 → AI 助手 → 额度 → 开启「使用 x-hub 平台额度」。需先在 设置 → 账号 登录并兑换邀请码获得积分。
- 开启后对话的模型下拉里出现一个「**x-hub 平台**」入口：平台配了几个模型你都不用管——只有一个就永远用它，多个自动轮询负载切换。
- 剩余积分显示在对话顶栏徽标与设置页；积分不足（429）时对话里出现「去兑换积分 / 配置自备 Key」分流卡。

**方式二：自备供应商（OpenAI 兼容）**

路径：设置 → AI 助手 → 供应商。

1. 「添加供应商」新建卡片，可用「快速填充」芯片一键填 DeepSeek / OpenAI / Moonshot / 阿里云百炼 / Ollama 等预设。
2. 填「供应商名称」「Base URL」「API Key」（**Key 只存系统钥匙串，不明文落盘**；界面脱敏，可眼睛查看/复制/更换）。
3. 「测试连通」验证地址与 Key；「获取模型」在线拉取模型列表勾选批量添加；中转站不支持拉取时用「手动添加模型」输入回车。
4. 每张卡的模型以标签展示，可复制/移除；**最后点「保存配置」才落盘**（卡片头部垃圾桶删除整卡）。

对话里的模型下拉按供应商分组列出所有模型；模型名旁有就绪指示点，灰点悬停可看原因（如平台未登录）。

### 7.3 对话操作

- 输入框 **Enter 发送、Shift+Enter 换行**，自动增高；生成中变「停止」按钮，点击中断本回合。
- 回复按 Markdown 渲染；代码块带语言标签与「复制」按钮；每条消息悬停可复制；上翻时出现「跳到底部」。
- 每回合底部统计：输入/输出/缓存 token、缓存率、速度（tok/s）。
- 「+」菜单：新建对话 / 切换对话 / 删除对话（独立窗与抽屉共用；重命名在 AI 助手视图左栏）。

### 7.4 Agent 工具与权限

x-hub 内置 Agent 能力，AI 可以调用工具读写本机数据（查待办、记笔记、启动应用等 34 个内置工具 + 扩展提供的工具）。

- **工具卡片**：AI 调工具时对话流中插入卡片——色点表示等级（读=绿 / 写=橙 / 危险=红），显示工具名与状态（执行中/等待确认/完成/失败/已拒绝），可展开看参数与结果；模型的中间叙述收进可折叠的「中间过程」块。
- **权限审批**：需要授权的操作卡片内出现三个按钮——「**允许**」（本次）、「**本会话允许**」（当前会话内同类操作不再问）、「**拒绝**」。危险操作默认展开参数防盲批。
- **权限档**：输入区快捷下拉「仅可查看 / 每次都问 / 完全权限」；默认档在 设置 → AI 助手 → 助手 →「AI 助手默认权限档」。选「完全权限」时可另开「危险操作仍需确认」保险。
- **扩展工具总开关**：设置 → AI 助手 → 助手 →「允许调用扩展提供的工具」；单个扩展的开关在该扩展的设置弹窗 →「AI 助手」区块（也是撤销授权的入口）。
- **「关于我」**：设置 → AI 助手 → 助手 → 多行文本框（≤1000 字），填写职业/偏好等，对话时作为背景注入，让回答更贴合你。

### 10.8 反馈

## 14. 应用更新

- **自动检查**：启动后每 4 小时静默检查一次；总开关在 设置 → 数据与关于 → 关于 →「自动检查更新」（默认开）。手动「检查更新」按钮不受开关限制，且会忽略「跳过此版本」记录。
- **发现新版本弹窗**：显示版本号、包大小与完整更新说明，三个按钮：
  - 「**立即更新**」：后台下载（断点续传、失败自动重试），进度条实时显示；下载中关掉弹窗下载继续；
  - 「**稍后再提示**」：30 分钟内不再打扰，到点自动补检；
  - 「**跳过此版本**」：不再提示该版本。
- **更新已就绪**：「立即重启」完成升级（自动替换，失败自动回滚）；不重启的话，下次启动也会自动完成安装。

## 15. 常见问题

**Q：点了关闭，程序还在后台？**
A：这是设计行为——关闭 = 最小化到托盘。彻底退出请右键托盘图标 →「退出」。

**Q：全局快捷键按了没反应？**
A：按顺序检查：① 设置 → 常规 → 快捷键 里该键是否被禁用（开关关闭）；② 是否与其他应用的热键冲突（改一个别的组合试试）；③ 改键时若提示「与『搜索』快捷键键值相同」，说明两个快捷键存了同一个键。

**Q：天气不显示？**
A：确认 设置 → 功能 → 联网 →「联网功能」已开启，且已在「天气城市」设置城市；离线时在线内容自动隐藏。

**Q：倒计时不走/没提醒？**
A：倒计时卡片从工作台布局移除后，非浮窗的倒计时会自动冻结（浮窗中的不受影响），把卡片加回即恢复。提示音默认关闭，需在 设置 → 工作台 开启。应用退出/休眠期间错过的提醒不补发。

**Q：AI 提示「平台额度未开启」或积分不足？**
A：平台模型需要：设置 → AI 助手 → 额度 开启开关 + 设置 → 账号 登录并兑换邀请码。积分不足时按对话里的「去兑换积分」或改用自己的 API Key（供应商）。

**Q：扩展页面一片空白？**
A：多见于窗口后台久了的渲染回收。点侧栏切换走再点回来，或右键侧栏该扩展图标 →「刷新页面」；service 型扩展可「重启后端」。

**Q：笔记里粘贴图片失败？**
A：仅支持 png/jpg/jpeg/webp/bmp/gif，单张 ≤10MB。

**Q：速达里程序图标模糊/像损坏？**
A：点速达头部「修复图标缓存」全量自愈（约几秒到几十秒）。

**Q：复制笔记内容到别处，图片带不过去？**
A：用 §5.6 的「复制图片」（灯箱按钮/右键/Ctrl+C），复制的是真实位图，可直接粘贴到聊天或文档。

**Q：换电脑/重装系统，数据怎么办？**
A：先在 设置 → 数据与关于 → 数据 →「备份」导出 zip；新机器装好后用「恢复」导入，或直接把整个数据目录（§1.3）拷到同位置。

**Q：便签/待办/提示词有独立小窗吗？**
A：有。便签卡可「脱离为悬浮便签」；待办卡右上角「待办浮窗」；提示词卡表头「提示词浮窗」。浮窗都可拖动、置顶，位置与开关状态会记住。

**Q：网页打不开（银行/内网站点）？**
A：应用内浏览器对部分站点有限制，右键该资源选「用系统浏览器打开」，或在面板工具栏点「用系统浏览器打开」。
